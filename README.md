# Guardian_Interfaz

Aplicación web sencilla para personalizar el nombre, el color de fondo y el tema
visual. Las preferencias se guardan en cookies nativas del navegador.

## Uso

Abre `index.html` en un navegador, elige tus preferencias y pulsa **Guardar Preferencias**, donde se mostrará un mensaje dandote la bienvenida y despues también mediante el botón **Restablecer Interfaz** elimina las cookies de la aplicación y restaura el aspecto inicial de la página.

Para que las cookies funcionen no abras el archivo directamente. En VS Code, abre el proyecto con la extensión Live Server y pulsa **Go Live**. También puedes probarlo en la dirección de GitHub Pages después de publicar el proyecto.

## Archivos

- `index.html`: estructura del formulario.
- `style.css`: estilos y temas claro/oscuro.
- `script.js`: eventos, cookies y creación dinámica de la bienvenida a la personalizacion de la página web.
